# Lanternfall (랜턴폴)

밤하늘의 한지 등불을 정해진 횟수의 탭으로 전부 터뜨리는 연쇄 퍼즐. 루멘폴의 자매작이다.
핵심은 둘, **예쁜 화면**과 **도파민**(팡팡 터지는 쾌감). 스토어 출시가 아닌 개인 작품이다.

- 지금 판: 시험판 8, 20단계 (1장 첫 밤, 2장 바람 부는 밤) + 인트로 화면, 밤하늘 지도, 제미나이 그림, 소리 세 겹
- 목표: 50단계, 인트로 화면, 제미나이 그림, 다듬은 소리
- **바로 하기: https://fifa3827-lgtm.github.io/lanternfall/**
- 게임 링크: https://claude.ai/artifact/5PK3uik1CtVrPwr56kocau (Claude 안의 시험판)

## 작업 원칙

- **한 답변에 한 덩어리.** 판 생성, 브라우저 검사, 스크린샷을 한 번에 몰면 답변이 중간에 끊긴다. 실제로 끊겼다.
- **모든 판은 두 번 검사한다.** `sim.py`로 답이 하나인지, 그리고 `e2e.py`로 실제 브라우저에서 정답이 깨지는지. 게임 코드의 규칙이 시뮬레이터와 어긋나면 두 번째 검사에서 잡힌다.
- **규칙을 알려주는 표시는 그림에 넣지 않는다.** 매듭, 금띠, 겉종이, 심지, 잠든 눈은 코드로 얹는다. 그림은 등불 몸통뿐.
- **사용자에게 보여주는 말은 한국어로만.** 제미나이 프롬프트도 한국어로 준다.
- 판단 기준은 늘 둘: 화면이 더 예뻐지는가, 터지는 순간이 더 커지는가.
